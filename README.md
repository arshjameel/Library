## Description
A simple CRUD application that serves as a way to manage a virtual library 
consisting of books read in the past or books you wish to read in the future.

The "read" status can be changed once a book has been added to the library.

## Note
1. This program is currently *not* responsive. 
    It is recommended to use the program on computer screens only.
2. Although the program is described as a CRUD application, it currently
    lacks the ability to edit data (such as title and/or author name) 
    once created.
3. The color palette used for this program was inspired by the 
    ["Gruvbox"](https://github.com/morhetz/gruvbox?tab=readme-ov-file) 
    colorscheme.
